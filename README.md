# qixin1 — 栖心一班 班级看板

静心学堂栖心一班的班级页面，经 GitHub Pages 发布：https://mp-shares.github.io/qixin1/

- `index.html` 班级看板（活动照片 / 班级公示 / 项目入口 / 义工操作区）
- `班费公示.html` 班费汇总 · `微岗位报名.html` 微岗位认领 · `班费账本.html` 记账（记账口令）
- `gate.js` 班级口令门 · `banfei.config.js` 后端地址

数据在 Google Drive（Sheet + Apps Script），页面本身不含任何数据。源文件与后端代码维护在 MPI义工运营 仓库（`运营·地区/DC1班陪伴/`、`scripts/banfei/`），改动后用 `scripts/banfei/publish.sh` 同步到这里。
